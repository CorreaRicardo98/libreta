# Hoja de ruta

Ideas ordenadas por cuánto ayudan a quien usa la app. No hay fechas: si algo te interesa, **tómalo**. Comenta en el issue correspondiente o abre uno nuevo.

## Más ayuda para quien escribe
- [ ] **OCR** de imágenes y escaneos, para poder buscar el texto que contienen.
- [ ] **Plantillas** de nota (reunión, diario, lista de compras…).
- [ ] **Recordatorios** en las tareas, con notificación del sistema y una vista «Hoy».
- [ ] **Recortador web**: guardar el contenido de una página, no solo el enlace.
- [ ] Abrir una nota en **ventana propia**.
- [ ] Más formatos de importación (Google Keep, Notion en HTML, Bear).

## Confianza y seguridad de los datos
- [ ] **Copia de seguridad automática** a un `.zip` con fecha.
- [ ] Cifrar también los **adjuntos** de las notas bloqueadas.
- [ ] Resolver conflictos cuando Syncthing/Nextcloud generan dos copias de una nota.
- [ ] Cambiar la contraseña de una nota bloqueada.

## Distribución
- [ ] **Actualización automática** desde las Releases de GitHub.
- [ ] Firmar los instaladores de Windows.
- [ ] Paquetes Flatpak, Snap y RPM.
- [ ] Instalador para macOS (el código ya es multiplataforma; falta compilarlo y probarlo).

## Comunidad
- [ ] **Traducción de la interfaz** (hoy solo está en español; falta inglés y el mecanismo para elegir idioma).
- [ ] Revisión de accesibilidad con lectores de pantalla.
- [ ] Más pruebas automáticas, sobre todo de la interfaz.

## Lo que Libreta no pretende ser
- Un servicio en la nube o con cuentas.
- Un editor colaborativo en tiempo real (requiere un servidor y deja de ser local). Compartir una carpeta sincronizada sí funciona.
